Оцени учебную гештальт-сессию. Клиент — симуляция. Ответь строго JSON:
{
  "progress": 0,
  "delta": 0,
  "resolved": false,
  "coreProblem": "краткая формулировка ядра проблемы клиента",
  "note": "1 предложение: что сдвинулось или почему ещё рано"
}

Правила:
- progress — итоговое значение 0..100 после этой сессии (учитывай previousProgress и качество работы терапевта в диалоге).
- delta — изменение относительно previousProgress (может быть 0 или отрицательным при срыве контакта).
- resolved=true только если устойчивое улучшение и клиенту реально может быть достаточно без терапевта (обычно progress >= 80 и есть явный сдвиг по ядру).
- Не ставь resolved=true после 1–2 коротких сессий без серьёзной работы.
- Язык: русский.
