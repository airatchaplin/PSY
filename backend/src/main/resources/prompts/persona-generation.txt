Сгенерируй нового взрослого клиента (18–80) для учебной гештальт-сессии.
Ответь строго JSON:
{
  "name": "имя",
  "age": 28,
  "gender": "MALE|FEMALE",
  "presentingRequest": "запрос своими словами",
  "difficulty": "EASY|MEDIUM|HARD",
  "behaviorTags": ["ANXIOUS"],
  "defenses": ["избегание"],
  "background": "краткая история",
  "currentLifeContext": "контекст сейчас",
  "relationalStyle": "как контактирует",
  "bodyCues": "телесные маркеры",
  "coreProblem": "ядро проблемы одним предложением",
  "openingLine": "первая реплика клиента на сессии"
}

behaviorTags — 1..3 значения строго из списка:
ANXIOUS, AVOIDANT, RATIONALIZING, BOUNDARY_TESTING, SHAME_PRONE, AFFECTIVE_CRYING, DEVALUING, FUSED_DEPENDENT, INTELLECTUALIZING

Пол и возраст:
- Если в запросе заданы gender и age — соблюдай их строго (имя согласуй с полом, age в JSON = заданный).
- gender влияет мягко через социализацию, НЕ как жёсткий стереотип: любые behaviorTags допустимы для обоих полов.
  · MALE: чаще уход в голову/контроль/минимизация уязвимости, стыд «слабости», тело как напряжение; может быть и аффектным.
  · FEMALE: чаще доступнее аффект и реляционное поле, фигуры вины/заботы; может и интеллектуализировать.
- Возраст задаёт поколенческий фон (темы, темп речи, жизненный контекст), не карикатуру:
  · 18–24: идентичность, сверстники, семья происхождения, соцсети;
  · 25–34: вехи карьеры/близости, долженствование;
  · 35–49: сжимающие роли, середина жизни;
  · 50–64: переоценка, смысл vs статус;
  · 65–80: пределы, потери/наследие, иной темп.

Сделай клиента уникальным. Язык ответа: русский.
